سؤال‌های رایج

مشکل دیگری داری؟ ↗
برای هر مدل گوشی فایل جدا لازم است؟ ＋

خیر. نسخهٔ مناسب به معماری اندروید وابسته است، نه فقط برند یا مدل گوشی. ARM64 برای اندروید ۶۴ بیتی و ARMv7 برای اندروید ۳۲ بیتی است. حتی بعضی پردازنده‌های ۶۴ بیتی ممکن است اندروید ۳۲ بیتی داشته باشند.

با آپدیت، اشتراک‌هایم پاک می‌شوند؟ ＋

نسخهٔ جدید را روی نسخهٔ رسمی قبلی نصب کن و برنامه را حذف نکن. شناسه و امضای اندروید حفظ شده‌اند. در ویندوز هم مسیر نصب قبلی شناسایی می‌شود.

دانلود تمام نمی‌شود؛ چه کنم؟ ＋

لینک را در مرورگر اصلی باز کن و بخش Downloads را بررسی کن. اگر دانلود ناقص مانده، از صفحهٔ انتشار دوباره فایل را بگیر. مسیر دانلود فایل‌ها GitHub است و ممکن است روی بعضی شبکه‌ها محدود باشد.

ویندوز دربارهٔ ناشر هشدار می‌دهد؟ ＋

نصب‌کننده فعلاً گواهی تجاری امضای کد ندارد؛ ممکن است SmartScreen هشدار دهد. فایل را فقط از انتشار رسمی دریافت کن و در صورت تردید، هش SHA256 را با فایل همراه انتشار مقایسه کن. ابزار امنیتی را خاموش نکن.

گوشی‌ات کدام است؟

برند گوشی به‌تنهایی معماری اندروید را مشخص نمی‌کند.

گوشی یا تبلت جدیدبا ARM64 شروع کن؛ برای بیشتر دستگاه‌ها مناسب است.گوشی قدیمی یا اندروید ۳۲ بیتینسخهٔ ARMv7 را انتخاب کن.شبیه‌ساز یا دستگاه Intelنسخهٔ x86_64 را با مشخصات دستگاه تطبیق بده.

اگر هنگام نصب «ناسازگار» دیدی، نسخهٔ اندروید و معماری سیستم‌عامل را در مشخصات دستگاه بررسی کن؛ اندروید ۸ به بالا لازم است.
